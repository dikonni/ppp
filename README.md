# Жасанды интеллекттің білім беру саласындағы мүмкіндіктері

Конференцияға арналған интерактивті 3D презентация (8 бет емес, 7 слайд).
Автор: Серікова Д.С. · Ғылыми жетекші: Чыншаева Н.Т.

## Іске қосу
`index.html` файлын браузерде ашыңыз (интернет тек Google Fonts шрифтіне керек).

## GitHub Pages
Repository → Settings → Pages → Branch: `main` / root → Save.

## Басқару
← / → немесе Бос орын — слайдтар, F — толық экран.

## Құрылым
- `index.html` — слайдтар
- `css/style.css` — стильдер
- `js/script.js` — навигация, 3D сахна (Three.js), курсор ізі
- `js/three.min.js` — Three.js r128
- `assets/` — логотип және скриншоттар
